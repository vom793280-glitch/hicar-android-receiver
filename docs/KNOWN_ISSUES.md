# 已知问题

## 手机搜不到、不弹 HiCar 提示

0.12.0 之前，发现广播只在热点准备成功后才启动，热点失败会连带关闭广播，现象就是“手机完全搜不到”。
0.12.0 已把两者解耦，并在“设置与诊断 → 7. 发现广播自检”里单独验证广播能力。

仍可能失败的情况：

- 车机蓝牙不提供 `BluetoothLeAdvertiser`（只有经典蓝牙），任何应用都无法让手机发现本机；
- 系统限制后台/前台服务的蓝牙广播；
- 手机端 HiCar 记录异常。

## 只有 2.4G 热点

0.12.0 解除了协议层与热点配置层的 5G 强制限制。仍需注意：

- 2.4G 的吞吐与抗干扰弱于 5G，画面可能卡顿或手机主动降低码率；这是物理限制，不是协议缺陷；
- Android 8/9 无法读取热点 BSSID 与信道，只能靠本机扫描或接口硬件地址推测，
  日志会注明“未经扫描核验”或“仅 SSID 方式上报”；个别手机要求严格匹配时会停在入网阶段；
- 取不到信道时按 2437 MHz（2.4G 信道 6）上报，若实际信道不同，手机可能拒绝入网。

## 重启后无法回连

0.11.0 已观察到接收服务、热点、蓝牙监听和发现广播启动成功，但手机未建立 HiCar 连接。手机的“自动连接”开启也不保证能连接。普通蓝牙重新配对曾恢复连接，但再次重启仍失败，原因未确定。

反馈时请说明：是否重启过接收端、普通配对是否成功、是否出现 HiCar 提示，以及接收页的状态。不要清除所有蓝牙或 HiCar 数据来替代诊断。

## 热点接口与权限

不同厂商会隐藏热点地址或限制接口。Android 8–10 使用 `startLocalOnlyHotspot(callback, handler)` 并回读
`WifiConfiguration`；Android 11 及以上使用 `SoftApConfiguration`，同时申请 2.4G 与 5G 信道。
系统启动回调必须保留本轮配置地址，并返回可用频道。不能取得可用参数时会按四级降级处理，
最终仍不可用才停止发送配置。接口调用结果不等于设备在无线侧采用该地址，仍需真实连接验证。

## 麦克风

语音实验默认关闭，仅在手机发起语音请求时采集。其他通话应用可能影响录音；出现识别问题时先结束接收端的其他通话，再做对照测试。开机自动接收不启动麦克风服务。

## 验证边界

编译成功、APK 安装成功、蓝牙接口注册、认证成功、解码器初始化都不分别等于完整可用。视频需以实际画面、声音需以实际听音、输入需以界面响应确认。

32 位原生库已构建，但尚无 32 位运行实测。车机和 HarmonyOS 5/6 发送端的兼容性待测试。
